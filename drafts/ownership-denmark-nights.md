## 새 편 / 새 권 추가 시 업데이트 절차

1. 원고 위치 확인: 새 편은 `~/workspace/market-fiction/volume-XX/episode-NN.md` (권이 늘면 volume 폴더가 는다). 원고 파일 안 제목(첫머리 `## Episode N: …`)을 그대로 페이지 제목으로 쓴다.
2. 페이지 추가: `denmark-nights/epNN.html` (두 자리 숫자, 0 채움). 기존 페이지 양식을 복사해 만든다 — `../style.css`, `../site.js`, 상단 nav는 `../` 접두, `.story-body` 인라인 스타일, 앞뒤 편 이동 링크(prev/next) 갱신.
3. 공개 범위 적용: 각 권(소설)의 첫 두 편만 전문으로 싣고, 세 번째 편부터는 페이지를 만들지 않는다 — 목록에 제목+한 줄 소개만 추가한다.
4. `index.html` 목록에 새 편 카드 추가 (제목 + 한 줄 소개; 링크와 전문 배지는 첫 두 편만).
5. 검수: 세 번째 편 이후의 본문이 어떤 페이지에도 없는지, 링크가 상대경로로 맞는지, 지어낸 구입 URL이 없는지 확인한다.
6. 게시는 총괄의 메뉴 통합·업로드 절차를 따른다. 이 폴더 밖 파일(사이트 메뉴·`index.html` 등)은 소유자가 건드리지 않는다 — 메뉴 통합은 총괄 담당.
