# 회차 mp3 자리

- 파일명 규칙: `ep001-제목-v1.mp3`처럼 회차 번호와 버전을 파일명에 넣는다.
- 수정본을 올릴 때는 내용만 교체하지 말고 **파일명을 바꿔** 올린다 (Spotify가 같은 이름이면 다시 가져가지 않음).
- 한 파일 100MB 이하 (GitHub 제한). 5분 회차는 128kbps 기준 약 5MB.
